# Getting Started

## What is Fluxora Modulith?

Fluxora Modulith is an IntelliJ IDEA plugin for analyzing and working with modular Java/Spring applications that follow Spring Modulith-style architecture.

It uses the current IntelliJ project structure and Java PSI to understand packages, types, and dependencies.

## Install

Install **Fluxora Modulith** from JetBrains Marketplace.

## Open the tool window

1. Open a Java/Spring project.
2. Open the **Fluxora Modulith** tool window.
3. Explore the module structure and dependency graph.
4. Use editor inspections to identify cross-module dependencies.
5. Use architecture verification to review module boundaries.

## Typical workflow

```text
Open project → Discover modules → Inspect structure → Review dependencies
→ Fix/configure dependencies → Verify architecture
```

Fluxora Modulith is designed to work with different project package names and does not require application-specific packages.
